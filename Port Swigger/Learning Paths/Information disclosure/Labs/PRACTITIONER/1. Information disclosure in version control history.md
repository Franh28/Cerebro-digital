fatal: bad object refs/heads/index.html

Cleaning up mistakenly downloaded directory index files.

Esto pasa porque `wget -r` también descargó las páginas de "listado de directorio" (`index.html`) que el servidor genera para carpetas como `/refs/heads/`, y Git las está confundiendo con archivos de referencias reales.

### Solución: borra los archivos `index.html` sobrantes

Desde dentro de la carpeta `.git`, borra todos los `index.html` que se colaron:

bash

```bash
find . -name "index.html" -delete
```

Esto eliminará los archivos de listado (como `refs/heads/index.html`, `objects/index.html`, etc.) que no son parte real del repositorio Git — solo dejará los archivos legítimos como `refs/heads/master`, `HEAD`, `config`, los objetos dentro de `objects/14/`, etc.

### Vuelve a intentar

bash

```bash
git log --all --oneline
```

Si **sigue fallando**, puede que falte algo más (a veces hay más basura de wget, como archivos `.tmp` o carpetas vacías). En ese caso, dime el error exacto y seguimos depurando.

Otra opción si quieres evitar este problema desde el principio en futuros intentos: usar `wget` con el flag `--reject "index.html*"` para que ni siquiera descargue esos archivos de listado:

bash

```bash
wget -r --reject "index.html*" https://TU-LAB-ID.web-security-academy.net/.git/
```

### Ahora mira el diff de ese commit

bash

```bash
git show 6df59c0
```

Esto te va a mostrar los cambios exactos de ese commit. Busca el archivo relacionado con la configuración de admin (probablemente `admin.conf` o similar) y fíjate en las líneas:

- Las que empiezan con `-` (en rojo normalmente) → es lo que **se borró**, ahí debería estar la contraseña en texto plano.
- Las que empiezan con `+` (en verde) → es lo que la reemplazó, probablemente la variable de entorno `ADMIN_PASSWORD`.

Debería verse algo como:

diff

```diff
diff --git a/admin.conf b/admin.conf
index ...
--- a/admin.conf
+++ b/admin.conf
@@ -1,3 +1,3 @@
-admin_password = "ContraseñaAquí"
+admin_password = os.environ['ADMIN_PASSWORD']
```

Pega aquí el resultado completo de `git show 6df59c0` y te confirmo cuál es la contraseña filtrada para que puedas iniciar sesión como admin.
