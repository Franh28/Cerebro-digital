El link que se genera en el nombre del autor del comentario es el link puesto en el campo de website, y se renderiza de la siguiente manera:
```
<a id="author" href="http://pepe.com" onclick="var tracker={track(){}};tracker.track('http://pepe.com');">pepe</a>
```

**Construcción de la URI paso a paso**

1. Empiezas con una URL cualquiera, por ejemplo `http://foo`
2. Le añades un `?` para simular un parámetro de query.
3. En vez de escribir una comilla simple literal (`'`), usas la entidad HTML `&apos;` — así el navegador la decodifica a `'` en el momento de renderizar el atributo, saltándose el escape del servidor.
4. Con esa comilla simple ya "dentro" del atributo, cierras el string de JavaScript, inyectas tu código, y vuelves a abrir un string vacío para que la sintaxis quede válida.

Entonces la payload final queda:

```
http://foo?&apos;-alert(1)-&apos;
```

Desglosado:

- `http://foo?` → URL base + inicio de query string
- `&apos;` → se convierte en `'` al renderizar, cerrando el string JS existente
- `-alert(1)-` → tu código: resta algo, ejecuta `alert(1)`, resta otra cosa (esto es solo para mantener sintaxis JS válida sin necesitar punto y coma ni paréntesis extra)
- `&apos;` → otra comilla simple que abre un nuevo string, para que lo que venga después en el `onclick` (si algo más sigue) no rompa la sintaxis
