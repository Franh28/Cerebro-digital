Vemos que al filtrar la búsqueda de los productos en la uri hay un parámetro category susceptible de ser vulnerable. De hecho cuando pones una ' sustituyendo el contenido después del = te da Internal Server Error.

En este caso te dicen que tipo de base de datos es, pero sino habría que irse al apartado de Data version de la cheat-sheet: https://portswigger.net/web-security/sql-injection/cheat-sheet

Antes buscamos el número de columnas para realizar esta operación con: 'ORDER+BY+2--
Vamos probando y vemos que da error a partir de 3

Luego, usando la cheat sheet ponemos '+UNION+SELECT+banner,NULL+FROM+v$version-- confirmando que es Oracle.

Luego para ver que campos son texto y cuales no variamos entre strings y NULL hasta que dé un 200 OK. Usamos 'UNION+SELECT+'abc'+'def'+FROM+dual-- y nos da el resultado buscado. Las dos son texto

El FROM dual sólo es necesario ponerlo cuando se trata de una base de datos Oracle, ya que siempre necesita el FROM en las queries que se realicen, al contrario que otras.
