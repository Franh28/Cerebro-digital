## Path Traversal (Salto de directorio)

El **Path Traversal** (o Directory Traversal) es una vulnerabilidad que permite a un atacante leer archivos del **servidor** que no deberían estar expuestos, moviéndose a través de las carpetas del sistema operativo.

- **Cómo funciona:** Se manipulan las variables que referencian archivos usando secuencias como `../` (subir un nivel).
    
- **El ejemplo clásico:**
    
    - La web carga una imagen así: `https://web.com/ver?archivo=foto.jpg`
        
    - El atacante lo cambia a: `https://web.com/ver?archivo=../../../../etc/passwd`
        
    - El servidor "sube" hasta la raíz y entrega el archivo de contraseñas del sistema Linux.

## IDOR (Insecure Direct Object Reference)

El **IDOR** ocurre cuando una aplicación confía demasiado en el usuario y le permite acceder a datos de otros simplemente cambiando un identificador (como un ID en la URL). Es un fallo de **control de acceso vertical u horizontal**.

- **Cómo funciona:** El sistema no verifica si el usuario tiene permiso para ver el objeto que está solicitando.
    
- **El ejemplo clásico:**
    
    - Entras a tu perfil: `https://tienda.com/ver_factura?id=100`
        
    - Cambias el número: `https://tienda.com/ver_factura?id=101`
        
    - **¡Boom!** Estás viendo la factura de otra persona.
