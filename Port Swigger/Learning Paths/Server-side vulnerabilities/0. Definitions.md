- **Authentication** confirms that the user is who they say they are.
- **Session management** identifies which subsequent HTTP requests are being made by that same user.
- **Access control** determines whether the user is allowed to carry out the action that they are attempting to perform.

- **Vertical privilege escalation**: a user can gain access to functionality that they are not permitted to access

- **Horizontal privilege escalation VS Vertical privilege escalation**: Often, a horizontal privilege escalation attack can be turned into a vertical privilege escalation, by compromising a more privileged user. For example, a horizontal escalation might allow an attacker to reset or capture the password belonging to another user. If the attacker targets an administrative user and compromises their account, then they can gain administrative access and so perform vertical privilege escalation

- IDOR:  insecure direct object reference, this type of vulnerability arises where user-controller parameter values are used to access resources or functions directly
 
- GUIDs: globally unique identifiers
 
- Authentication VS Authorization: Authentication is the process of verifying that a user is who they claim to be. Authorization involves verifying whether a user is allowed to do something. For example, authentication determines whether someone attempting to access a website with the username `Carlos123` really is the same person who created the account. Once `Carlos123` is authenticated, their permissions determine what they are authorized to do. For example, they may be authorized to access personal information about other users, or perform actions such as deleting another user's account.
