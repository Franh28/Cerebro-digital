**El mensaje enviado por el iframe atacante:**

js

```js
postMessage("{\"type\":\"load-channel\",\"url\":\"javascript:print()\"}", "*")
```

Aquí el dato (`e.data`) ya no es HTML suelto, sino un **string con formato JSON**. Las barras invertidas (`\"`) son solo para poder escribir comillas dentro de un string de JavaScript que ya está delimitado por comillas; el JSON real, una vez "desescapado", es:


```json
{"type":"load-channel","url":"javascript:print()"}
```


**Qué hace el script receptor:**

```js
d = JSON.parse(e.data);
```

Convierte ese string en un objeto JS: `d.type === "load-channel"` y `d.url === "javascript:print()"`.

Luego entra en el `switch`:

```js
case "load-channel":
    ACMEplayer.element.src = d.url;
    break;
```

Esto crea un reproductor (un `<iframe>` nuevo, `ACMEplayer.element`) y le asigna `src = d.url`. Como `d.url` vale `javascript:print()`, el navegador interpreta ese `src` como una **URL con esquema `javascript:`** y ejecuta el código directamente
